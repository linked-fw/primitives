# 002 — The ontology in the index layout

## PR

**What changed.** The core this release builds on removed `linkedOntology` and no package
registers a prefix; an ontology package declares its ontologies in `package.json` and the cli
generates the modules that register them.

- `package.json`: `"linkedOntologies": {"primitives": {"namespace":
  "https://linked.cm/ont/primitives/", "data": ["primitives.ttl"]}}`.
- `src/data/primitives.ttl` (new): the `owl:Ontology` node with title, description,
  `vann:preferredNamespacePrefix "primitives"` and `vann:preferredNamespaceUri`.
- Generated by `linked generate-ontology`: `src/ontologies/primitives.ts` (no terms, so an empty
  module) and `src/ontologies/index.ts` (`registerOntologies([{name: 'primitives', …, suggestedPrefix:
  'primitives'}], import.meta.url)`); `src/index.ts` imports the index.
- Removed: `src/ontologies/primitives.register.ts`; `Prefix.add('primitives', …)`; the `ns`,
  `_self`, `primitives` and deprecated `radix` exports (nothing in the framework imports them).
- `src/package.ts`: exports `registerOntologies` in place of `linkedOntology`.

Major changeset (`.changeset/ontology-index.md`).

The built index, imported in Node: `suggestedPrefixes()` →

the registration's `files` are `[ '../data/primitives.ttl' ]` and `load()` returns the Turtle
(`lib/esm/data/primitives.ttl` is in the build).

**Deviations.** The generator added `import './ontologies/index.js'` to `src/index.ts` but left the
import of the deleted hand-written `primitives.register.js` (it rewrites only imports of register
modules it generated itself); removed by hand.

**Follow-ups.** None in this repo; the `@_linked/core` and `@_linked/react` ranges move to the new
majors at release. The generator gap above belongs to the cli (reported with this step).
